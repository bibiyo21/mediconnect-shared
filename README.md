# mediconnect-shared

Shared TypeScript packages for MediConnect apps, published as versioned `@mediconnect/*` npm packages: `api-client`, `shared-types`, `validation`, `design-system`, `business-rules`, `configuration`.

`api-client` and `shared-types` are generated from the OpenAPI document of a pinned mediconnect-backend release, never edited by hand.

Not scaffolded yet: built in Phase 1, increment 8. Contract flow: [mediconnect-docs](https://github.com/bibiyo21/mediconnect-docs) `docs/architecture.md` §5.
